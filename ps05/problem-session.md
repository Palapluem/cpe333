# Problem Session 5: Virtual Memory

## 1. Understand the concept of virtual memory

1. Explain and compare how virtual memory is implemented in modern Linux and MS Windows.
2. Show step-by-step how to increase or decrease swap space in Linux, with screenshots.

## 2. Understand Linux VM monitoring

1. Run the `free` command in the Linux shell.
2. Capture the output and explain everything shown by this command.
3. Summarize all numerical values shown by this command in a paragraph.
4. Use `free --help` and select two useful arguments of the `free` command. These could be a combination of multiple arguments if it is interesting. For each argument:
   - Describe what it does.
   - Show a sample command and explain the output.
5. If you do not have `vmstat`, install and run it in the Linux shell.
6. Capture the output and explain everything shown by this command.
7. Summarize all numerical values shown by this command in a paragraph.
8. Use `vmstat --help` and select two useful arguments of the `vmstat` command. These could be a combination of multiple arguments if it is interesting. For each argument:
   - Describe what it does.
   - Show a sample command and explain the output.

> **Note:** Capture an output image from running both the `free` and `vmstat` commands.

## 3. Understand Windows VM monitoring

1. Open **Resource Monitor**, or use the `resmon` command in PowerShell.
2. Capture the output and explain the information shown on the interface related to memory monitoring.
3. Summarize all numerical values shown in the **Physical Memory** tab in a paragraph.
